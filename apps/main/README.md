# Hanhaga

מערכת ניהול והערכה לקורסי מנהיגות, עם ממשק RTL בעברית, הרשאות לפי תפקיד ועדכונים בזמן אמת.

## מה המערכת עושה

Hanhaga מרכזת במקום אחד את ניהול החניכים, צוות ההדרכה, מפגשי הקורס, מבחנים, ציונים, נוכחות והערות מעקב. כל משתמש רואה ממשק ונתונים בהתאם לתפקיד שלו:

- **חניך (`student`)** - צפייה באירועי הקורס, סטטוס נוכחות, מבחנים שפורסמו, ציונים לפי קטגוריה והערכה מילולית מהמדריך.
- **מדריך (`instructor`)** - עבודה עם חניכי המחלקה, הזנת ציונים, הערות מילוליות, תיק מעקב אישי וסימון נוכחות במפגשים.
- **מנהלן (`assistant`)** - הזנת ציונים עבור מבחנים שהוגדרו כגלויים למנהלנים.
- **מנהל (`admin`)** - שליטה מלאה במשתמשים, מבחנים, אירועים, דוחות, הגדרות וחשיפת נתונים.
- **מפקח (`inspector`)** - גישה לדוחות, פילוחים וכרטיסי חניכים, ללא מסכי ניהול משתמשים, מבחנים ואירועים.

## Stack

### Frontend

- React 19.2 עם React DOM ו-Vite 7.
- JavaScript מודרני עם ES modules.
- Tailwind CSS 4 דרך PostCSS ו-`@tailwindcss/postcss`.
- Lucide React לאייקונים.
- גופן Assistant, תמיכה מלאה ב-RTL ובעיצוב responsive mobile-first.
- History API לניווט פנימי, כולל תמיכה בכפתורי Back/Forward בדפדפן.

### Backend and data

- Firebase App לצורך אתחול האפליקציה.
- Firebase Authentication עם anonymous auth כחלק מאתחול הסשן.
- Firebase Phone Authentication עם reCAPTCHA v3 ו-OTP לאנשי צוות.
- Cloud Firestore עם `onSnapshot` לעדכונים בזמן אמת.
- Firebase App Check עם reCAPTCHA v3.

### Tooling and quality

- ESLint 9 עם `eslint-plugin-react-hooks` ו-`eslint-plugin-react-refresh`.
- Playwright ו-`@axe-core/playwright` עבור בדיקות browser ונגישות.
- Autoprefixer ו-PostCSS.
- תשתית עזר לבדיקת ממשק ב-`scripts/ui-audit-runner.mjs`.

## יכולות לפי תחום

### התחברות והרשאות

- התחברות לפי שם ומספר טלפון עם נרמול קלטים.
- חניכים יכולים להתחבר ללא שליחת SMS כדי לצמצם עלויות.
- אנשי צוות מתחברים באמצעות SMS OTP.
- שמירת פרופיל מקומי ב-`localStorage` כדי לשמר את מצב המשתמש בין טעינות.
- ניתוק והחזרה למסך ההתחברות.
- אפשרות למנהל מורשה לסגור זמנית את האתר למשתמשים.

### ניהול משתמשים

- יצירה ועריכה של חניכים ואנשי צוות.
- שיוך תפקיד, מחלקה ובית ספר.
- חיפוש וסינון חניכים לפי שם, טלפון ומחלקה.
- ייבוא משתמשים המוני מקובץ CSV.
- ייצוא דוח CSV הכולל פרטי חניך, נוכחות וציוני מבחנים.
- מחיקת משתמשים.
- תגיות פרופיל לצרכים תפעוליים ורפואיים, כולל פרטים עבור רגישות, אלרגיה ומצב רפואי חריג.
- תמיכה ברשימת בתי ספר מוגדרת מראש ובאווטארים לפי תפקיד.

### מבחנים והערכה

- יצירת מבחן עם קטגוריות ניקוד.
- הגדרת ניקוד מקסימלי לכל קטגוריה.
- אימות שסכום הקטגוריות הוא 100.
- עריכת מבחנים קיימים.
- חשיפה נפרדת למדריכים ולחניכים.
- מצב `showVerbalOnly` להצגת הערכה מילולית לפני חשיפת הציון המספרי.
- הזנת ציונים לפי קטגוריה והגבלת הציון למקסימום שהוגדר.
- שמירת הערה מילולית של המעריך.
- הצגת ציון כולל, פירוט קטגוריות והערת המדריך לחניך לאחר פרסום.

### אירועים ונוכחות

- יצירה, עריכה ומחיקה של אירועי קורס.
- סוגי אירועים: מפגש, מסע, יום היערכות ויום חשיפה.
- תאריך, שעה ומיקום לכל אירוע.
- יום חשיפה מסומן כאירוע שאינו עוקב אחר נוכחות.
- יצירת מפגשי ברירת מחדל כאשר אוסף האירועים ריק.
- סימון חניכים כ"נכח" או "נעדר" לפי מפגש.
- תצוגת יומן אירועים וסטטוס נוכחות באזור האישי של החניך.

### תיק חניך ומעקב

- תיק אישי למדריך עם נקודות לשימור, נקודות לשיפור ומעקב לאורך הקורס.
- הצגת ההערות בכרטיס החניך למדריכים ולמנהלים.
- הצגת תגיות רלוונטיות בכרטיסי משתמשים.
- הצגת פירוט נוכחות, ציונים והערות במסך פרופיל חניך למנהל.

### דוחות וניתוח נתונים

- דוח חניכים עם סינון לפי מחלקה וחיפוש.
- מספר החניכים הרשומים.
- התפלגות חניכים לפי בית ספר.
- ממוצעי ציונים לפי מחלקה וממוצע קורס.
- שיעורי נוכחות לפי מפגש.
- תצוגת ציונים ונוכחות בכרטיס חניך.
- ייצוא נתונים ל-CSV להמשך עבודה חיצונית.

## מודל הנתונים ב-Firestore

הנתונים הציבוריים של האפליקציה נשמרים תחת הנתיב הבא:

```text
artifacts/{appId}/public/
  config                 הגדרות אתר ומצב סגירה
  data/
    users/               פרופילים לפי מספר טלפון מנורמל
    exams/               מבחנים וקטגוריות ניקוד
    grades/              ציוני חניך לפי studentId ו-examId
    attendance/          מפות נוכחות לפי חניך ומפגש
    notes/               תיק אישי לפי חניך
    events/              אירועים, מפגשים, תאריכים ומיקומים
```

החניך מקבל שאילתות ממוקדות עבור הציונים, ההערות והנוכחות שלו. אנשי צוות מקבלים סנכרון רחב יותר לצורך ניהול, דוחות ופילוח.

## התקנה והרצה

דרישות מוקדמות: Node.js נתמך ו-npm.

```bash
npm install
npm run dev
```

פקודות זמינות:

```bash
npm run dev       # שרת פיתוח Vite
npm run build     # בניית production
npm run preview   # הגשת build מקומי
npm run lint      # בדיקת ESLint
```

## תצורה

לפני פריסה יש לבדוק את:

- `src/config/firebase.js` - Firebase project, Authentication, Firestore ו-App Check.
- `src/config/constants.js` - כתובות נכסים, רשימת בתי ספר, תפקידי משתמשים ותגיות.
- `firestore.rules` - הרשאות קריאה וכתיבה לנתוני Firestore.
- `firebase.json` - הגדרות Firebase לפריסה.

לפרויקט יש Firebase project ID מוגדר כברירת מחדל בקוד. בסביבת production מומלץ לנהל ערכי תצורה ו-secrets באמצעות מנגנון תצורה מתאים, להגביל App Check והרשאות Firestore, ולא להשאיר קודי צוות או מפתחות תפעוליים בקוד client.
